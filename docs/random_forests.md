# Random Forest Models

## Purpose and inputs

This component fits three random forests to predict in-hospital death from the
first 48 hours of Set A. Inputs use cleaning version `BP_RULE_B_V1` and feature
version `COMMON_COVARIATES_V2` in `data/processed/common_covariates_v2/`.
All three sets include Age, Gender, and ICUType: Values has 114 raw predictors,
Patterns has 77, and Combined has 188. Combined includes the common covariates
only once. RecordID, Height, severity scores, and outcome-derived fields are
excluded from the predictors.

The updated inputs are generated by `scripts/13_add_common_covariates.py` from
the measurement-only tables produced by `scripts/06_build_features.py`.
The shared assignments are copied unchanged. Their SHA256 is
`96ce6b957987236e0d3ede0e8b475190cc340b4762447e9d22906ad188110828`.
The model reads these assignments rather than generating a new split. Team
integration should compare this hash or the complete RecordID-to-split/fold
mapping against the assignments actually used for the other models.

## Methods

All models use the same 3,200 training stays, 800 test stays, and five training
validation folds. Both the train/test split and training folds are stratified
by `In-hospital_death`. Tables are aligned by RecordID.

Each pipeline median-imputes numeric columns, including Age, and one-hot
encodes Gender and ICUType. Missing categorical values are labeled `Missing`;
the encoder uses `drop=None`, `handle_unknown="ignore"`, and dense output.
An unseen category produces an all-zero block for that variable. Gender uses
0=female and 1=male; ICUType uses 1=coronary care, 2=cardiac surgery recovery,
3=medical ICU, and 4=surgical ICU. These are categories, not ordered predictors.
The categorical convention matches the updated LASSO workflow.

Numeric imputation, category learning, and constant-column removal are fitted
separately within each fitting fold, followed by the random forest. Entirely
missing numeric fitting-fold columns are filled with zero and removed if
constant. No extra missingness indicators or standardization are added. Zero
measurement counts are retained, and no stays are dropped for missing predictors.
The Patterns measurement columns are complete; its common covariates can be missing.

The three feature sets use the same prespecified grid:

| Setting | Values |
| --- | --- |
| Trees | 300 (fixed) |
| Maximum depth | 8 or unrestricted |
| Minimum samples per leaf | 10 or 2 |
| Features considered per split | Square root of retained predictor count or 50% |
| Class weighting | None |
| Random seed | 707 |

There are eight candidates and five fits per candidate for each feature set.
Each feature set selects its own candidate with the highest mean validation
AUROC. An exact tie selects the first candidate in scikit-learn's ParameterGrid
order. This is a modest search, not an exhaustive optimization. Scores used to
select a candidate are tuning scores, not an unbiased estimate of final performance.

The selected pipeline is refitted on all training stays and produces one death
probability per test stay. The training script does not compute test AUROC, Brier
scores, calibration curves, thresholds, or test-driven model revisions. Xiaoning's
evaluation component will perform the common test-set comparison.

## Reproduction

Set up and activate the [shared project environment](environment.md).
This component uses Python 3.11.18 and the same root
[requirements.txt](../requirements.txt) as the other analysis scripts.

Obtain Set A and the agreed assignment file. Place the assignment file at
`data/processed/split_assignments.csv` before building features. Do not delete it
to generate a replacement split. The supplied raw-data downloader is available
if the raw files are not already present.

```bash
python scripts/download_data.py
python scripts/06_build_features.py
python scripts/13_add_common_covariates.py
python scripts/12_train_random_forests.py --mode check
python scripts/12_train_random_forests.py --mode tune --jobs 4
python scripts/12_train_random_forests.py --mode predict --jobs 4
```

Script 13 creates the V2 input directory once and refuses to overwrite an
existing directory. Skip it when the current V2 inputs are already prepared.

`--mode all` runs tuning and prediction together. Prediction verifies that input
file hashes and Python/package versions still match those recorded at tuning. A changed environment or source
dataset should be documented and validated before replacing an existing result.

## Interpretation

Values has no explicit measurement-missingness indicators, but median imputation
can leave recognizable patterns. Value summaries may also reflect the recording
process, so this comparison does not isolate measurement values completely from
missingness information. The Missing category for admission covariates is shared
by all three feature sets.

Test AUROC, Brier score, calibration, and paired-bootstrap differences between
Combined and Values belong to the common evaluation step. Training CV scores
alone do not establish a meaningful improvement, and this analysis does not
validate transportability across hospitals.
